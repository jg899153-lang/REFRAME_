전시 콘셉트 02

RE:FRAME — 영화의 장면을 다시 보다. 익숙한 장면의 구도와 색, 공간을 새롭게 해석하고 정지 이미지에서 움직이는 영상으로 이어 갑니다.

사용 도구 03

GPT 이미지 생성 도구 · ComfyUI · Google Flow · 영상 편집 도구. 작품마다 필요한 도구를 선택해 이미지와 움직임을 연결합니다.

제작 과정과 프롬프트 04

레퍼런스 분석 → 장면 구성 → AI 이미지 생성 → 영상 생성 → 편집. 실제 제작에 사용한 프롬프트 원문은 작품별 기록과 함께 추후 공개합니다.
